# Aset 3D SiPeSa (landing page)

Drop file PNG **transparan** di folder ini. Nama harus persis seperti di bawah.
Jika file belum ada, landing page otomatis pakai fallback CSS/SVG (tidak rusak).

| File | Dipakai di | Saran ukuran |
|------|-----------|--------------|
| `hero.png` | Hero (mascot + 3 tong + gedung + globe) | ~1120×940, transparan |
| `dashboard.png` | Section "Alur" (laptop preview dashboard) | ~1200×800, transparan |
| `mascot.png` | CTA band (maskot petugas) | ~400×400, transparan |
| `avatar-1.png` | Testimoni 1 (foto) | 200×200 |
| `avatar-2.png` | Testimoni 2 (foto) | 200×200 |

Export tiap elemen 3D dari tool gambar sebagai PNG transparan terpisah,
lalu taruh di sini. Refresh browser — gambar langsung gantikan fallback.
